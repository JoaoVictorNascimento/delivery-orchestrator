# Agent Instructions

Read `docs/product/PRODUCT_VISION.md`, `docs/product/PRD.md` and `docs/ROADMAP.md` before changing the project. Treat requirements as proposed baseline; do not silently change product behavior. Record significant architectural choices using ADRs.

Use English in public artifacts. Never access or copy corporate project material into this repository. Use synthetic data in tests and demos. Preserve existing user changes. Do not create real MRs, push, merge, or modify external repositories during tests. Do not expose credentials or disable quality gates. Report actual test results and blockers. Do not mark work complete solely because files exist.

During parallel development respect assigned ownership and shared contracts. Coordinate interface changes through the integration owner. Prefer simple, testable modules and document trade-offs.
