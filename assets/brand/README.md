# Delivery Orchestrator — Brand Kit v1.0

Production vector candidate based on the approved identity. Copy `assets/brand/` and review the updated `docs/design/BRAND_GUIDELINES.md` against your repository. No repository license or existing files are modified by this package.

## Quick usage

- Light UI: `logos/logo-horizontal-light-no-tagline.svg`
- Dark UI: `logos/logo-horizontal-dark-no-tagline.svg`
- Marketing: `logos/logo-horizontal-dark.svg` or light equivalent
- Collapsed sidebar: `icons/symbol-color.svg`
- Browser: `icons/favicon.svg` and `icons/favicon.ico`
- GitHub: `social/github-preview.png` and `social/github-avatar.png`
- Tokens: `tokens/brand.css` / `tokens/brand.json` (brand-only; not the shadcn preset)
- Visual reference: `guidelines/vector-brand-board.png`

All logo text is outlined geometry. SVGs contain no embedded raster or external font dependencies. The symbol uses editable strokes and curves. PNG and ICO are derived raster exports. The visual guide SVG uses live text for its explanatory labels only.

Do not store corporate assets or credentials in this directory.
